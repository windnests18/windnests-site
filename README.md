# WindNests Free Website

This is a static, mobile-first website for WindNests.

## Publish for free with GitHub Pages
1. Create a GitHub account.
2. Create a NEW PUBLIC repository named `windnests-site`.
3. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
4. Open Settings → Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. GitHub will give you a free Pages URL.
8. Later connect `windnests.com` under Settings → Pages → Custom domain.

## Before publishing
- Replace the placeholder hero/product blocks with your real WindNests images.
- Replace the WhatsApp links with your business WhatsApp number.
- Replace the email if needed.
- Add your real product prices and product photos.

The site is static and does not include payment/checkout processing yet.
